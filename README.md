# MediaHub

Одно окно в браузере (http://127.0.0.1:8765): загрузка видео/аудио/сайтов/манги, библиотека, игры.

Запуск: `start.bat` (нужен Python 3; ffmpeg и deno кладите в папку `ffmpeg` рядом).

## Как устроено
Тёмный интерфейс, в центре обложки. Открывается библиотека; слева: «Добавить», «Библиотека», «Входящие», «Загрузки», «Игры», «Настройки».

* **Входящие и расширение для браузера.** Расширение (папка `extension`, Chrome и Edge) отправляет выбранные вкладки в приложение:
  текущую, отмеченные, группу или все вкладки окна. Приложение показывает предпросмотр: тип материала, что сделать
  (скачать, следить за обновлениями, только сохранить ссылку, пропустить), что уже есть в библиотеке и какие вкладки закроются.
  Ничего не скачивается, пока вы не подтвердите список. Вкладка закрывается только после успешной загрузки (за 5 секунд
  расширение предупреждает, можно отменить); при ошибке, отмене или неполной загрузке она остаётся открытой, и приложение
  пишет причину. Закрытую вкладку можно вернуть кнопкой в журнале «Входящих».
  Установка в Яндекс Браузере, Chrome, Edge, Brave (в Яндексе адрес `browser://extensions`): `chrome://extensions` → «Режим разработчика» → «Загрузить распакованное расширение» → папка `extension`.
  Подключение подтверждается кнопкой «Разрешить» в приложении. Расширение видит только адрес и название отправленных вкладок;
  пароли, cookies, история и закладки не читаются.
* **Библиотека**: обложки с названием, категории со счётчиками, поиск (клавиша `/`), группировка по автору или теме,
  сортировка. Тип «Ссылки» — сохранённые источники без файлов (кнопка «Скачать» на карточке). Изменить и удалить: при наведении.
  Манга открывается во встроенной читалке и запоминает место.
* **Добавить**: ссылки и тип (видео, аудио, манга, сайт). «Дополнительно»: выбор страниц сайта, диапазон глав, расписание,
  список ссылок из файла. «Проверить размер» показывает, сколько займёт загрузка и сколько места останется.
* **Загрузки**: ход, скорость, оставшееся время, отмена; внизу экрана полоса загрузки.
* **Манга**: по умолчанию загрузка идёт **в вашем браузере** через расширение (Яндекс Браузер, Chrome, Edge): на время загрузки
  оно открывает небольшое окно сайта под вашим входом, берёт список глав и адреса страниц (режимы «Лента» и «По страницам»),
  а MediaHub скачивает картинки параллельно. Окно загрузки не закрывайте, в конце оно закрывается само. Готовые главы
  при повторном запуске пропускаются, ошибки пишутся в `download.log`. Запасной вариант («Отдельным окном» в настройках):
  собственный браузер MediaHub через Playwright; для него можно взять cookie из Firefox (работает всегда) или из Edge/Chrome
  (они шифруют cookie и блокируют базу, пока открыты, поэтому нужно закрыть браузер).
* **Игры** (вкладка «Игры», две части):
  **Библиотека** в стиле Playnite: обложки с названием, в правом нижнем углу кружок (✓ скачано, пустой — не скачано), плашка «Обновление».
  Щелчок по карточке открывает слева панель: версия у вас и последняя, разработчик, движок, система, язык, дата выхода, размер, жанры
  (щелчок по жанру включает фильтр), описание, ссылки на скачивание, «Следить за новыми версиями», заметка. Сортировка (название, недавно
  добавленные, с обновлением, размер, дата выхода), фильтры «Скачано / Не скачано / Есть обновление» и по жанрам.
  Карточка создаётся из вкладки с темой игры: во «Входящих» выберите «Добавить игру в библиотеку» (или вставьте ссылку на тему в самой
  вкладке). Расширение читает страницу в вашем браузере под вашим входом; MediaHub разбирает название, версию, жанры, обложку и ссылки.
  Установленные игры из папки (настройки) сливаются с карточками по названию. «Проверить обновления» (и расписание в настройках)
  открывает темы по одной с паузой и сравнивает версии. **Версии и чистка**: GameSweep (старые версии, Корзина; двойной щелчок по строке
  открывает папку; любую версию можно выбрать, актуальную только с подтверждением). Файлы игр из библиотеки не удаляются и не переносятся.
  **Какая папка чья.** Связь «карточка ↔ папка» запоминается: в базе (таблица `links`: путь, способ, время) и, для карточек с темой и при ручной
  привязке, в файле `.mediahub.json` внутри папки игры (адрес темы и ключ названия). Если папку переименовали или перенесли, а по названию
  она уже не находится, игра узнаётся по маркеру. Маркер не меняет игру и порядок версий (время файла не новее остального); отключается в «Настройках»
  («Помечать папки игр»). «Проверить, скачана ли» теперь объясняет, почему не нашлось: ближайшая папка, процент и что мешает.
* **Настройки** (сохраняются сами): папка, качество видео, формат звука, субтитры, обложки, число загрузок,
  лимит скорости, параметры сайтов, окно браузера для манги, cookie, папка игр, подключённые расширения.

**Сайты.** Списки сайтов манги, видео, аудио и игр лежат в одном файле `sites.json` (домены, путь тайтла, откуда разрешены картинки, нужен ли доступ расширению).
Из него берут данные `app.py` и интерфейс (`/api/sites`), а расширение получает `extension/sites.js` и `host_permissions` в `manifest.json` командой
`python tools/gen_sites.py` (с ключом `--check` только проверяет). Тесты следят, чтобы сгенерированное не устаревало и чтобы приложение и расширение
определяли тип страницы одинаково. Зеркала можно добавить без правки файла: `MEDIAHUB_SITE`, `MEDIAHUB_MANGA_HOSTS` (через запятую).

**mangabuff.ru.** Профиль с `engine: mangabuff` скачивает мангу без Playwright: страницы тайтла и глав берутся как HTML (через расширение MediaHub под вашим входом,
а без него обычным запросом), список глав и адреса страниц читает `engine_mangabuff.py`, картинки качаются с нужным Referer. Движок проверен на сохранённых
страницах сайта (`tests/fixtures/mangabuff`). Новые сайты со своей разметкой добавляются так же: профиль в `sites.json` и модуль-разборщик.

**Nude-Moon.** Профиль `engine: nudemoon` скачивает комикс целиком как одну «главу» (глав у сайта нет): новая вёрстка (`/view/{id}-…`, все страницы на одной странице)
и старая (`/{id}-….html` со ссылкой «Читать онлайн»). Теги, автор, переводчик и описание сохраняются в `manifest.json` и показываются на карточке. Адреса сайта меняются:
новые зеркала добавляются в переменную `MEDIAHUB_MANGA_HOSTS=хост=nudemoon` или в `sites.json` (`suffixes`).

**Игры из нескольких источников.** Карточка игры хранит сборки каждого сайта отдельно (F95zone, PornoLab, Byrutor): у каждой своя версия, размер, язык (русский есть
в интерфейсе, в озвучке или только в субтитрах), цензура, ссылка на страницу, `.torrent` и magnet. Теги всех сборок объединяются, а «есть обновление» срабатывает,
если новее установленной версии любая из сборок. Для PornoLab ссылка `.torrent` открывается только после входа на сайт. Приложение сами раздачи не скачивает:
оно запоминает страницу, версию и ссылку. Проверка версий («Проверить обновление») читает страницу каждого источника своим разборщиком (`engine_games.py`).

**Доступ с других устройств (Wi-Fi).** В «Настройках» → «Доступ с других устройств»: задайте PIN (не короче 6 символов), включите переключатель и перезапустите MediaHub.
Адрес для телефона покажет та же строка (например, `http://192.168.1.5:8765`), его же печатает консоль при запуске. Что можно с другого устройства: смотреть,
читать, слушать и сохранять место, где остановились. Всё остальное (загрузки, настройки, удаление, игры, расширение) и пути на диске остаются только на компьютере
с приложением. Вход по PIN, 5 ошибок с одного адреса блокируют вход на 5 минут, «Выйти на всех устройствах» закрывает сессии. Режим выключен по умолчанию и без PIN не включается.
Windows при первом включении спросит про брандмауэр: разрешите доступ **только для частных сетей**. Соединение идёт по HTTP без шифрования, поэтому включайте режим
только в своей сети с паролем, но не в кафе или отеле. Для доступа из другого города или по мобильной сети используйте VPN (Tailscale, WireGuard), а порт в интернет не открывайте.
Место, где остановились, общее для всех устройств (профилей пользователей нет).

**Версии и чистка.** Раздел «Игры» → «Версии и чистка» это родной раздел приложения, а не встроенное окно: у него нет своего сервера, токена и отдельной темы, он работает
через `/api/versions/*` и общий `Store` из `gamesweep.py` (там остались только логика и самопроверка `python gamesweep.py --selftest`). Папка игр одна на всё приложение:
при сканировании она запоминается в настройках. Возможности те же: группы версий, поиск (слова, `-исключить`, `>500мб`, чужая раскладка, опечатки), фильтры, выбор «все старые»,
отправка в Корзину с вариантами обращения с сохранениями (копировать, пропустить, удалить вместе), отдельное подтверждение для актуальных версий, а на вкладке «Вкладки браузера»
сверка списка ссылок с играми на ПК и экспорт списков. Всё управляется с клавиатуры (клавиша «/» ведёт к поиску), статусы подписаны текстом.

**Лента.** Раздел «Лента» собирает, что нового: версия игры изменилась на сайте-источнике, у манги появились новые главы, у отслеживаемого канала или плейлиста вышло новое видео.
Общий механизм: проверить источник, сравнить с тем, что уже известно, записать событие (оно уникально, поэтому повторная проверка того же факта ничего не дублирует).
Первая проверка канала только запоминает, что на нём уже есть. Приложение ничего не скачивает само: у события есть кнопки «Скачать новые главы», «Скачать видео» или «Открыть страницу»,
«Прочитано» и «Убрать». Проверки: игры через расширение (по странице за раз, как «Проверить обновление»), манга со своего сайта (пока только mangabuff; у senkuro и Nude-Moon
список глав так не читается, лента честно пишет, у скольких тайтлов проверка недоступна), видео через `yt-dlp` без скачивания. Расписание: «Настройки» → «Проверять ленту каждые, часов»
(0 — только по кнопке). Число непрочитанного видно в меню; каналы и плейлисты добавляются в самой ленте.

## Скорость
Плейлисты и каналы качаются несколькими видео сразу; манга: страницы главы параллельно, пока браузер листает
следующую (картинки и реклама в самом браузере отключены); ресурсы сайтов качаются в 8 потоков.

## Безопасность
Сервер слушает только 127.0.0.1; проверяется заголовок Host (защита от DNS-rebinding), управляющие запросы
принимаются только из окна MediaHub (заголовок X-MH + проверка Origin); GameSweep закрыт собственным токеном.

Расширение подключается только после вашего согласия в приложении; доступ идёт по секретному токену, который хранится
в `ext.json` рядом с программой (не копируйте этот файл другим людям).

## Доступность

Интерфейс рассчитан на WCAG 2.1 AA: работает с клавиатуры и скринридера, поддерживает крупный текст, высокий контраст и светлую тему.

**Режимы отображения** (Настройки → Отображение, хранятся в браузере): размер текста 100 / 125 / 150 %, контраст обычный или высокий, тема тёмная, светлая или как в системе, крупные цели нажатия (не меньше 44 пикселей), горячие клавиши.

**Горячие клавиши** (отключаются в Настройках или кнопкой в справке):

| Клавиши | Действие |
|---|---|
| `g`, затем `l` / `i` / `d` / `g` / `s` | Библиотека / Входящие / Загрузки / Игры / Настройки |
| `g`, затем `n` | Журнал уведомлений |
| `j` / `k` | Следующая и предыдущая карточка |
| `/` | Поиск |
| `?` | Справка по клавишам |

**Уведомления.** Сообщения живут 8 секунд (пауза при наведении и фокусе), ошибки остаются до закрытия. Колокольчик в боковой панели открывает журнал последних 50 сообщений, действия из пропавших уведомлений доступны там же.

**Плеер** (`/p/<id>`, открывается из Библиотеки для видео и аудио). Позиция запоминается сама: раз в 5 секунд, на паузе, в конце и при закрытии вкладки; при следующем открытии воспроизведение продолжается с того же места («С начала» возвращает к началу). Позиция короче 5 секунд не сохраняется, а досмотренное (осталось не больше 10 секунд) снова играет с начала. Субтитры подхватываются автоматически: положите рядом с файлом `<имя>.srt` или `<имя>.<язык>.srt` (также `.vtt`; кодировки UTF-8 и Windows-1251; `ru` показывается как «Русский», `en` как «English»).

| Клавиши плеера | Действие |
|---|---|
| `k` | Воспроизведение и пауза |
| `j` / `l` | Назад / вперёд на 10 секунд |
| `[` / `]` | Медленнее / быстрее (0.5–2, шаг 0.25) |
| `c` | Субтитры: следующая дорожка, затем выключить |
| `m` / `f` | Звук / полный экран (`f` только для видео) |
| `?` | Справка |

**Читалка манги** (`/m/<id>`). Режимы «По ширине», «По высоте», «Исходный размер» и масштаб 50–200 % (запоминаются в браузере); смена главы клавишами `n` / `p` или `→` / `←` (в «Исходном размере» при горизонтальной прокрутке стрелки прокручивают страницу, а главы переключаются `n` и `p`); `w` / `h` / `o` режим, `+` / `-` / `0` масштаб, `?` справка. Работающие клавиши плеера и читалки действуют только при включённых горячих клавишах и не мешают вводу текста; русская раскладка поддерживается по физической клавише.

**«Продолжить».** В Библиотеке над списком показаны до 6 недосмотренных видео, аудио и начатых манг (свежие первыми). Кнопка с крестиком убирает материал из блока (для манги это стирает и сохранённую страницу). Блок скрыт при поиске и при выбранном фильтре.

**Тесты** (папка `tests/`, не входят в поставку): `pip install -r tests/requirements-dev.txt`, затем `python -m playwright install chromium` и `python -m pytest tests -v`. Положите `axe.min.js` из npm-пакета `axe-core` в `tests/vendor/`, иначе axe-проверки пропускаются. Ручные чек-листы для скринридера: `docs/a11y-manual-stage1.md` и `docs/a11y-manual-stage2.md`.
