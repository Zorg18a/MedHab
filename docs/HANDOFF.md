# MediaHub: передача проекта в новый чат

Читать в начале нового чата **вместо** перечитывания кода. Здесь карта, команды, шаблоны, ловушки и что осталось. Актуально на конец шага 6.

## 1. Что это
Локальное приложение «загрузчик + библиотека» (Python stdlib + SQLite, без Node и фреймворков), интерфейс в браузере на `http://127.0.0.1:8765`.
Скачивает видео/аудио (`yt-dlp`), мангу, сайты; ведёт библиотеку, игры (версии, источники, обновления), ленту новинок, раздел «Версии и чистка».
Расширение браузера (`extension/`) присылает вкладки и читает страницы под вашим входом. Язык интерфейса и ответов: русский.

## 3. Как запускать тесты
```
python -m pytest tests -x -q                          # есть pytest + playwright (chromium)
python tools/offline_tests/run.py tests               # нет pytest: подмена, ~5 минут весь набор
python tools/offline_tests/run.py tests/test_feed.py  # один файл
python tools/offline_tests/run.py tests -k имя_теста  # по части имени
python gamesweep.py --selftest                        # логика GameSweep (69 проверок)
python tools/gen_sites.py --check                     # актуальность сгенерированного для расширения
```
**База: 505 passed, 0 failed, 6 skipped** (6 — автопроверки `axe`, нужен `tests/vendor/axe.min.js`). После любой правки число не должно падать.
Полный набор запускать в фоне и читать только хвост: `(nohup ... > /tmp/out.txt 2>&1 &)`, затем `tail -3 /tmp/out.txt`.
Тестовые переменные окружения: `MEDIAHUB_NO_BROWSER=1`, `MEDIAHUB_PORT`, `MEDIAHUB_TEST_ALLOW_LOCAL=1` (разрешить localhost в `guard`), `MEDIAHUB_TEST_REMOTE=1` (считать и свой компьютер «чужим»: для тестов сети), `MEDIAHUB_GAME_DELAY`, `MEDIAHUB_FEED_DELAY`, `MEDIAHUB_LAN=1`.

## 4. Шаблоны (делать так же)
* **Новый сайт манги:** профиль в `sites.json` (`engine`, `name`, `hosts`, `path` с ОДНОЙ группой, `permission`) → `python tools/gen_sites.py` → `engine_<имя>.py` (чистый разбор) → драйвер в `app.py` (`manga_http` / `manga_nudemoon` — образцы) и запись в `by_engine` → фикстуры из **присланных пользователем** страниц (урезать, убрать ники) → тесты: парсеры, сквозная загрузка с подставной сетью, ветка в `tests/test_sites.py::TABLE`. Без образца страницы сайт не делать: селекторы наугад ломают загрузку.
* **Сквозной тест без сети:** копия проекта во временную папку + `driver.py` в подпроцессе, который делает `import app` (импорт безопасен), подменяет `app.fetch_html`, `app.Fast`, `app.list_videos`, `app.ext_online`, `app.time.sleep`, и печатает `RESULT{json}`. Образцы: `tests/test_mangabuff.py`, `test_nudemoon.py`, `test_feed.py`, `test_game_sources.py`.
* **API-тест:** фикстура `server` (общий сессионный сервер; перед каждым тестом чистятся `items`, `feed`, `watch`…), `jget/jpost` из `test_game_find.py`, `server._sql(...)` для прямой вставки в БД. Настройки, которые тест меняет, возвращать в `finally`.
* **UI-тест:** фикстура `page` (Playwright), `page.get_by_role(...)`, ждать через `wait_for_function`, а не мгновенные проверки (бейдж обновляется асинхронно).
* **Доступность (обязательно для UI):** у каждой кнопки/флажка имя; состояние текстом, не только цветом; фокус не теряется после действия (перевести на соседний элемент или заголовок); ошибки `role="alert"` + `aria-invalid`; диалоги через `js/ui/dialog.js` (возврат фокуса); ссылки в `target=_blank` с `rel="noopener noreferrer"`.

## 6. Ловушки (уже наступали)
* **Вывод в консоль:** `cut -c`, `head -c` режут кириллицу посреди символа и ломают вывод. Использовать `python3 -` для чтения кусков файлов.
* Вывод инструментов показывает `\\` вдвое (JSON-экранирование): проверять реальным запуском, а не глазами.
* **Playwright strict mode:** `get_by_role("button", name="Нет на ПК")` совпадает и с «Нет на ПК…»; ставить `exact=True`.
* `guard(url)` ходит в DNS: без сети отказывает. Для проверки при добавлении использовать `guard_literal` (без DNS).
* Нельзя форматировать HTML/CSS через `%`: в CSS есть `100%`. Брать метки `@@X@@` и `.replace`.
* `is_private` в Python считает «частными» и документационные адреса (192.0.2.x): для сети свой список `lan.LAN_NETS`.
* Маркер `.mediahub.json` не должен становиться «самым свежим» файлом папки: GameSweep считает новизну по самому свежему файлу внутри.
* Сгенерированные `extension/sites.js` и `manifest.json` руками не править.
* Папка `extension-firefox/` и `MediaHub-Firefox.zip` в проекте устарели (в плане Firefox «убран»): не обновляются, лучше удалить.
* Ключ карточки манги `manga:{slug}` общий для сайтов: одинаковый slug на двух сайтах склеит карточки (у Nude-Moon приставка `nm-`).

## 7. Доступ с других устройств: как пользоваться
Компьютер, где запущен MediaHub, остаётся «сервером»; телефон, планшет и другие ПК в **том же Wi-Fi** открывают приложение в браузере по его адресу.
1. На компьютере: «Настройки» → «Доступ с других устройств» → задать **PIN** (не короче 6 символов) → «Сохранить PIN» → включить переключатель → **перезапустить MediaHub**.
2. Windows при первом запуске спросит про брандмауэр: разрешить **только для частных сетей**.
3. В настройках появится адрес вида `http://192.168.1.5:8765` (его же печатает консоль при запуске). Открыть его на телефоне, ввести PIN.
4. Гость может смотреть, читать, слушать, сохранять место, где остановился. Загрузки, настройки, удаление, игры, расширение и пути на диске только на самом компьютере.
5. Защита: 5 ошибок PIN с одного адреса блокируют вход на 5 минут; «Выйти на всех устройствах» закрывает сессии. Соединение без шифрования: только свой Wi-Fi, не кафе. Для доступа из другого города VPN (Tailscale), порт в интернет не открывать.
Код: `lan.py`, обёртка `gate()`/`login()` в `app.py`, тесты `tests/test_lan.py`.

## 8. Как не тратить контекст
* Не читать файлы целиком: `grep -n`, затем срез через `python3 -`. `app.py` ~1700 строк, читать по 20–40 строк.
* Не печатать большие ответы инструментов: хвост (`tail -3`) и только упавшие тесты (`grep "^FAIL"`).
* Страницы сайтов в тестах только урезанные фикстуры, а не полные сохранения (там сотни КБ).
* Один шаг плана = один чат. В конце шага: полный прогон → обновить этот файл (раздел 5) → zip → новый чат.
* Новую логику делать **чистыми функциями** в отдельных модулях (как `feedlib`, `engine_*`): их тесты быстрые и короткие, правки в `app.py` минимальные.
