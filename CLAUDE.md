# MediaHub: правила для Claude (читать первым)
Полная карта, команды и ловушки: `docs/HANDOFF.md`. План: `docs/PLAN.md`. Здесь только правила.

* Язык ответов и интерфейса: русский. Ответы короткие: что сделано, что проверено, что не проверено. Без воды.
* Не читать файлы целиком (`app.py` ~1700 строк): `grep -n` + срез. Не использовать `cut -c`/`head -c` (ломают кириллицу).
* Тесты: `python -m pytest tests -q` или `python tools/offline_tests/run.py tests`. База **505 passed, 6 skipped**; падать числу нельзя. Полный набор в фоне, читать хвост.
* Новая логика: чистые функции в отдельном модуле + тесты; в `app.py` минимум. Контроль «тест падает без реализации» для нового поведения.
* Сайты: только через `sites.json` + `python tools/gen_sites.py`; для нового сайта нужен **образец страницы от пользователя**, наугад не делать.
* UI: доступность обязательна (имена, текст вместо цвета, фокус после действий, `role="alert"`); использовать `js/ui/*`, `js/core/*`.
* Безопасность: сеть только по PIN (`lan.py`); новые маршруты `/api/*` по умолчанию закрыты для гостей; не логировать и не отдавать `lan_pin_*`; внешние адреса через `guard`.
* Адреса в базе/логах не выдумывать; ничего не качать и не запускать без явного действия пользователя.
* В конце шага: прогон, обновить статус в `docs/HANDOFF.md`, собрать zip в `/mnt/user-data/outputs`.
